# Retrospectiva Final — Programa MorEnvíos (Semanas 1 a 8)

## 1. ¿Qué logramos? (Aciertos del equipo)
* **Crecimiento técnico:** Comenzamos con maquetación básica y terminamos integrando un carrito de compras dinámico, consumiendo APIs en Python y conectando un buscador con Inteligencia Artificial.
* **Trabajo en equipo:** La comunicación fue clave. Aprendimos a usar ramas en Git, a resolver conflictos de código y a diagnosticar errores entre los dos (por ejemplo, cuando el frontend no conectaba con el backend).
* **Mentalidad de seguridad:** Aprendimos a proteger la interfaz de usuario, mitigando ataques XSS (cambiando `innerHTML` por `textContent`) y asegurando que el usuario final reciba respuestas claras y seguras.

## 2. ¿Qué fue lo más difícil? (Deuda y retos)
* **Integración del Frontend con la IA:** Fue un reto diseñar la interfaz no solo para cuando la IA funciona, sino para cuando falla. Lograr que el *fallback* (mensaje naranja) se viera bien y no rompiera el diseño requirió mucha prueba y error.
* **Manejo de estados (LocalStorage):** Sincronizar el carrito visual con el almacenamiento del navegador y luego con la base de datos al hacer checkout fue complejo, pero nos enseñó muchísimo sobre el flujo de datos.
* **Diagnóstico de errores (Debugging):** Aprender a usar la consola del navegador (F12) y detectar cuándo un archivo JS no se estaba cargando o cuándo había un error de CORS fue todo un tema al principio.

## 3. Plan de mejora (Para la vida profesional)
* Aprender a usar herramientas de diseño como Figma para planear la interfaz antes de escribir el código HTML.
* Escribir pruebas automatizadas no solo para el backend, sino también para el frontend.
* Mantener los estilos en archivos CSS separados y usar clases reutilizables desde el primer día.

## 4. Conclusión
Cierro este servicio social con mucha más confianza en mis habilidades como desarrolladora. Logramos construir un e-commerce real, seguro y con IA. Siento que ahora estoy preparada para enfrentar el proyecto real.
