<h2>## Semana 1 — Ingeniería de software + Git/GitHub</h2>

### Conceptos aplicados
- **Issue**: registra una necesidad o tarea antes de tocar código.
- **Rama (branch)**: entorno aislado para trabajar sin afectar `main`.
- **Commit descriptivo**: usa prefijos claros (`feat:`, `fix:`, `docs:`) explicando qué cambió y por qué.
- **Pull Request (PR)**: solicita integrar los cambios de una rama a `main`, con revisión previa.
- **Protocolo 4C**: Comprender → Consultar → Comprobar → Comunicar, antes de escalar una duda.
